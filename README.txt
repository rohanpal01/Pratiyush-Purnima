# Pratiyush & Purnima — Wedding Invitation Sample

Open `index.html` in a browser.

Included:
- Envelope opening animation
- One-page scroll invitation
- Smooth reveal animations
- Countdown to 25 Nov 2026
- Haldi / Mehndi / Sangeet / Wedding / Reception cards
- Gallery using the supplied photos
- Music button
- Optional `music.mp3` support
- Responsive mobile design
- RSVP demo form
- Venue section for PS Lawn

For the final version:
1. Replace/add the exact venue address + Google Maps link.
2. Add the final wedding details and timings.
3. Put the chosen background song in this folder as `music.mp3`.
4. Connect RSVP to WhatsApp, email, Google Sheet, or a backend if desired.
5. Deploy the folder to any static hosting service to get a shareable link.
